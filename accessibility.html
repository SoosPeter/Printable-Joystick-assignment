Accessibility statement

Pannalgorin Interactive tries very hard to provide an accessible website for the target audience. We aim to conform to WCAG 2.2 Level AA.

Accessibility features

  • Semantic landmarks: header/nav/main/footer
  • Keyboard operability
  • Skip-to-content link
  • Consistent navigation across pages
  • Form labels and clear instructions; validation messages are announced via ARIA live regions

Feedback and contact

If you notice accessibility barriers, contact us via the contact page. Please include the page URL and a description of the issue.
